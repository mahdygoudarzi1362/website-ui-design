# Responsive Design Guidelines

Responsive behavior is part of the design and must be implemented before final QA.

## Viewports

At minimum validate:

- Desktop
- Tablet
- Mobile

Use the behavior of the layout to choose breakpoints rather than assuming every device needs a separate breakpoint.

## Check at each viewport

- Header and navigation
- Hero or main visual area
- Grid and card layout
- Typography and line breaks
- Buttons and controls
- Images and media
- Spacing and alignment
- Overflow and horizontal scrolling
- Visibility and stacking order

## Rule

Do not only shrink the desktop layout. Reconsider hierarchy, stacking, spacing, and interaction when the available width changes.
