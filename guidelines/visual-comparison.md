# Visual Comparison QA

## Standard loop

Reference screenshot → actual screenshot → identify differences → fix → capture again → compare again.

## Difference priority

Review differences in this order:

1. Overall layout and dimensions
2. Positioning and spacing
3. Typography and line wrapping
4. Components and visual details
5. Colors, borders, shadows, and imagery
6. Responsive behavior

## Comparison rule

Use the same relevant viewport dimensions for the reference and actual screenshot whenever possible.

Pixel-perfect matching is required only when the project explicitly calls for it. Otherwise prioritize faithful structure, hierarchy, spacing, typography, and visual intent.
