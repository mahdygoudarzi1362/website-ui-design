# Projects

Project-specific documentation lives here.

## Suggested structure

```text
projects/
└── project-name/
    ├── README.md
    ├── reference/
    ├── decisions.md
    └── qa.md
```

## Project README

Record:

- Target website
- Technology/theme/builder
- Reference source
- Scope
- Constraints
- Approved visual direction

## decisions.md

Record important implementation decisions, especially decisions that affect integration with the existing site.

## qa.md

Record screenshots, viewport sizes, identified differences, fixes, and final QA status.

Projects may be implemented on websites that are not connected to GitHub. GitHub is only the documentation and workflow source in this repository.
