# Screenshot-to-Code

Official project: https://github.com/abi/screenshot-to-code

Screenshot-to-Code is used in this workflow as a rapid visual prototyping tool. It can turn screenshots and other visual references into code that can then be reviewed and adapted.

## Supported output stacks

The project's current documentation lists HTML + Tailwind, HTML + CSS, React + Tailwind, Vue + Tailwind, Bootstrap, and Ionic + Tailwind.

## Local application

The documented local application uses a React/Vite frontend and FastAPI backend.

## Model providers

The application requires at least one supported model-provider API key. API keys must never be committed to this repository.

## Screenshot Preview

The project documents an optional Screenshot Preview based on Chromium/Playwright. Use preview rendering when it helps compare generated output with the reference.

## Production rule

Generated code is a prototype. Review structure, CSS scope, JavaScript behavior, assets, accessibility, responsiveness, and integration requirements before production use.
