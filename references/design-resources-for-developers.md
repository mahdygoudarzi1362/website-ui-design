# Design Resources for Developers

Source: [bradtraversy/design-resources-for-developers](https://github.com/bradtraversy/design-resources-for-developers)

## Why it belongs here

This repository is a curated directory of design and UI resources: assets, fonts, icons, stock imagery, templates, CSS frameworks, UI libraries, and related tools.

We use it as a **discovery reference**, not as a design system and not as a reason to add dependencies automatically.

## Reusable rules

- Prefer existing project assets and an established design system before introducing new resources.
- When an asset is needed, choose it deliberately for the intended visual role and licensing constraints.
- Treat external resource lists as discovery sources; verify the current resource, license, API, and maintenance status before production use.
- Do not let a resource directory determine the visual style of a product. Visual decisions still come from requirements, references, evidence, and the project's design system.
- Avoid adding a library merely because it appears in a curated list; verify fit, bundle/runtime impact, accessibility, and maintenance first.

## When to use

Use this reference during asset discovery, visual prototyping, typography/icon exploration, or when a project needs a candidate UI/CSS resource.
